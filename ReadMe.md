> ### About this fork (gregesposito)
> Adds **distance display**: your target's distance and each party member's distance appear next to their bars. A member's distance turns **red when they're more than 20 yalms away**, which makes it easy to spot a multi-box character that has stopped following.
>
> Settings (in `data/settings.xml`, created on first load): `ShowTargetHPPercent`, `ShowTargetDistance`, `ShowPartyTP`, `ShowPartyDistance`, `ShowRanges` (all `true` by default).
>
> **Load:** copy to `Windower/addons/TParty/`, then `//lua load tparty`. It has no commands; it's display only.

---

# TParty

Shows a target's HP percentage next to their health bar and displays party and alliance member's TP. Unlike SE's version of TP display this also works on Trusts. Both options can be disabled in the settings.
